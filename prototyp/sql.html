Datenbank-Update

Diese Seite kopiert das Update für die zentrale Rundenfreigabe vollständig in die Zwischenablage.

Wird geladen …

  1. Tippe oben auf „Update kopieren“.
  2. Öffne den leeren SQL Editor mit dem Knopf unten.
  3. Tippe in das leere Feld, halte den Finger gedrückt und wähle „Einfügen“.
  4. Prüfe: Die erste Zeile beginnt mit /* MTG Tour: Update, und die letzte Zeilennummer ist ….
  5. Tippe auf „Run“ und bestätige die Warnung.
Leeren SQL Editor öffnen

Richtig eingespielt ist es, wenn unten in Supabase „Update für die Rundenfreigabe ist eingespielt“ steht.

Falls das Kopieren nicht klappt: Der Text steht auch hier. Feld antippen, „Alle auswählen“, „Kopieren“.
